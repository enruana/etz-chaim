# Bitácora del proyecto

Historia de decisiones y estado de «La Biblia», en orden más o menos cronológico. Es la versión portátil de las notas que Claude Code fue guardando mientras construíamos la app; viaja con el repo para poder seguir el trabajo desde cualquier computador. Lo estable (reglas, flujos, dónde está cada cosa) vive en `CLAUDE.md`; aquí va el porqué de cada decisión y lo que se aprendió en el camino. Al cerrar una tarea se añade una entrada al final.

Las fechas son las del día en que se tomó la decisión o se desplegó el cambio.
